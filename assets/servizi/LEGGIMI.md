# Loghi dei servizi dei bar

Qui vanno i loghi che compaiono accanto ai servizi nella scheda di un bar.
Il nome del servizio salvato su Firestore (campo `services` del bar) deve
contenere la parola indicata; il file deve avere esattamente questo nome:

| Servizio contiene | File                 |
|-------------------|----------------------|
| SuperEnalotto     | `superenalotto.png`  |
| Mooney            | `mooney.png`         |
| Amazon            | `amazon.png`         |

Usa i file ufficiali forniti ai punti vendita (kit del rivenditore o area
stampa del marchio), PNG con sfondo trasparente, alti almeno 66 px.
Finché un file manca, l'app mostra un'icona generica al posto del logo.
